皆様、こんにちは。Configuration Manager / WSUS サポート チームです。

本記事では、Configuration Manager current branch を対象に、Windows クライアント上で CCMSetup.exe を管理者権限で実行してクライアントをアンインストールし、ログで結果を確認するまでの動作をご案内します。パッケージを展開して複数の端末からアンインストールする方法は対象外です。

Configuration Manager コンソールの [削除] は、サイト データベースからクライアントのレコードを削除する操作です。端末上のクライアント ソフトウェアをアンインストールする操作とは異なります。

## 全体の流れ

1. 端末上でアンインストールを開始する
2. クライアント ソフトウェアを削除する
3. CCMSetup プロセスの終了を待つ
4. CCMSetup.log でアンインストールの結果を確認する

アンインストールの結果は画面に表示されません。CCMSetup プロセスの終了と、アンインストールの成否は分けて確認します。

## 各ステップとログの追跡方法

### 関連ログ

| ログ名 | 保存場所 | 主な用途 |
| --- | --- | --- |
| CCMSetup.log | クライアントの `%windir%\ccmsetup\logs` | クライアントのセットアップ、アップグレード、削除に関する CCMSetup.exe の処理が記録されます。アンインストール全体の結果を確認するログです。 |
| client.msi.log | クライアントの `%windir%\ccmsetup\logs` を確認します (ファイルがある場合)。 | 今回のアンインストールに対応する記録がある場合に、client.msi が実行した処理の詳細を確認する補足ログです。 |

ここでは各ログの用途と確認する観点を示します。実際のログの抜粋や、個々のログ メッセージと工程の対応例は掲載していません。

### ステップ 1 : 端末上でアンインストールを開始する

対象の Windows クライアントでコマンド プロンプトを管理者として開きます。CCMSetup.exe があるフォルダーに移動し、アンインストールを指定して実行します。以下は、CCMSetup.exe が `%windir%\ccmsetup` にある場合の例です。

```cmd
cd /d "%windir%\ccmsetup"
CCMSetup.exe /uninstall
```

実行した時刻を控えておくと、CCMSetup.log にセットアップやアップグレードの記録もある場合に、今回のアンインストールに該当する箇所を見つけやすくなります。

### ステップ 2 : クライアント ソフトウェアを削除する

CCMSetup.exe は、アンインストールの指定を受けて、端末上の Configuration Manager クライアント ソフトウェアを削除します。バージョン 2111 以降では、クライアントのブートストラップである ccmsetup.msi が存在する場合、それも削除されます。

削除処理を追うときは、まず CCMSetup.log で今回の実行に該当する記録を確認します。client.msi が実行した処理を詳しく確認する場合は、実行した時刻と両方のログの記録時刻を照合し、同じアンインストールに対応する記録が client.msi.log にあるかを確認します。ファイルがあっても、今回の実行時刻に対応する記録がなければ、その内容は今回の結果の判断には使えません。

### ステップ 3 : CCMSetup プロセスの終了を待つ

後続の作業を始める前にアンインストール処理の終了を待つ必要がある場合は、CCMSetup プロセスの実行中に、PowerShell で次のコマンドを実行します。

```powershell
Wait-Process CCMSetup
```

このコマンドは CCMSetup プロセスが終了するまで待機します。待機が終わったことは処理の成功を示すものではないため、続けて CCMSetup.log で結果を確認します。

### ステップ 4 : CCMSetup.log でアンインストールの結果を確認する

`%windir%\ccmsetup\logs\CCMSetup.log` を開き、実行時刻を手がかりに、今回のアンインストールの終了時に記録された結果を確認します。失敗が記録されている場合は、同じ実行分の直前の記録をたどり、どの処理でエラーが発生したかを確認します。終了時の記録が見当たらない場合は、プロセスが終了しているか、参照している記録が今回の実行に対応しているかを確認します。

client.msi.log で個々の処理の結果を確認できても、このログだけではアンインストール全体の成否は確認できません。最終的な結果は CCMSetup.log で確認します。
