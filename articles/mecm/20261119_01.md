皆様、こんにちは。Configuration Manager / WSUS サポート チームです。

本記事では、Windows コンピューターで `CCMSetup.exe /uninstall` を実行して Configuration Manager クライアントをアンインストールするときの処理の流れとログの用途を説明します。
コレクションに対してパッケージを展開する方法もありますが、展開後の配布や実行の詳細は扱いません。また、アンインストール内部の段階、手動で行う完全削除、および再インストールの手順も対象外です。

本記事では、Microsoft Learn に記載された手順とログの用途を紹介します。実環境のログを使って各工程を時系列に追跡したものではないため、実ログの抜粋や実在しない成功メッセージは掲載しません。

## 全体の流れ

アンインストールの流れは、次のとおりです。

1. 管理者としてコマンド プロンプトを開き、`CCMSetup.exe /uninstall` を実行します。
2. 必要に応じて、`CCMSetup` プロセスが完了するまで後続のスクリプトを待機させます。
3. 画面には処理結果が表示されないため、`CCMSetup.log` を参照してアンインストールの結果を確認します。

## 各ステップとログの追跡方法

### 関連ログ

| ログ名 | 保存場所 | 主な用途 |
| --- | --- | --- |
| `ccmsetup.log` | クライアントの `%windir%\ccmsetup\logs\CCMSetup.log` | クライアントのセットアップ、アップグレード、および削除に関する `ccmsetup` タスクを記録します。アンインストール結果の確認やクライアント インストール問題のトラブルシューティングに使用します。 |

### ステップ 1 : アンインストール コマンドの実行

管理者として Windows コマンド プロンプトを開き、`CCMSetup.exe` があるフォルダーへ移動して次のコマンドを実行します。

```console
cd %windir%\ccmsetup
CCMSetup.exe /uninstall
```

個々のコンピューターではコマンド プロンプトから実行できます。コレクション内のコンピューターを対象にする場合は、クライアントをアンインストールするパッケージを展開する方法もあります。

### ステップ 2 : 必要に応じた処理完了の待機

アンインストールが完了するまで後続の操作を待たせる必要がある場合は、PowerShell で次のコマンドを実行できます。

```powershell
Wait-Process CCMSetup
```

このコマンドは `CCMSetup` プロセスが完了するまでスクリプトを一時停止します。プロセスの終了を待機するものであり、それだけでアンインストールの成功を判断するものではありません。結果は次のステップでログを確認します。

### ステップ 3 : ログによるアンインストール結果の確認

アンインストール コマンドの実行結果は画面に表示されないため、Microsoft Learn ではクライアント上の `%windir%\ccmsetup\logs\CCMSetup.log` を参照して成功を確認するよう案内しています。`ccmsetup.log` はクライアントの削除を含む `ccmsetup` タスクを記録するログです。本記事では実ログを使った工程追跡を行っていないため、ログ内の個別の記録とステップ 1・2 との対応は示していません。

Configuration Manager バージョン 2111 以降では、アンインストール時に、存在する場合はクライアント ブートストラップの `ccmsetup.msi` も削除されます。

参照した Microsoft Learn の記載には、アンインストールの内部工程やログ内の特定の成功メッセージは示されていません。そのため、本記事ではフォルダー、レジストリ、証明書などの削除順序や、ログの具体的な記録を示していません。実際の結果を詳しく確認する場合は、対象端末で取得した `CCMSetup.log` を参照してください。
